Weather · Temperature · Clothing

9/25–10/6 天气 & 穿衣速查

以下为这段时间的历史气候参考，实际出发前仍需看短期预报。Rockies 海拔高、昼夜温差大，9月底已经可能遇到降雪或结冰。

Vancouver 温哥华

约 11–18°C

温和、可能有雨。长裤 + T恤/薄针织 + 轻薄防水外套即可。

Banff 班夫

约 0–16°C

早晚很冷、温差明显。保暖内层 + 抓绒/薄羽绒 + 防风防水外壳。

Lake Louise 露易丝湖

约 -2–14°C

清晨可能低于0°C。看湖或徒步建议薄羽绒、帽子和手套。

Icefields Parkway 冰原大道

约 -3–10°C

风大、变化快，可能有雪/结冰。薄羽绒 + 防水硬壳，车内备额外保暖层。

Toronto 多伦多

约 8–18°C

典型初秋。长裤 + 长袖/针织 + 轻外套即可。

Montréal 蒙特利尔

约 4–13°C

早晚明显偏凉，可能下雨。毛衣/针织 + 中等厚度外套。

Québec City 魁北克城

约 2–12°C

比蒙特利尔更凉。毛衣/抓绒 + 中等外套，郊区建议随身带薄羽绒。

最简单的打包原则：整趟采用“洋葱式分层”。城市秋装即可；Rockies 额外准备薄羽绒或抓绒、防风防水外壳、徒步鞋、帽子和手套。

Shared Essentials

两套路线共用的重点体验

Lake Minnewanka 明尼旺卡湖 Cruise

适合作为 Banff 班夫 的低体力开场，湖上视角比单纯岸边停留更完整。

Larch Hike

9 月底最具季节性的体验之一。天气窗口优先级高于固定行程。

Banff 班夫 Hot Springs

安排在徒步或湖区活动后的晚上，不占用白天天气窗口。

Art · Museums · Churches

值得保留的文化项目

Museum of Anthropology · UBC 不列颠哥伦比亚大学人类学博物馆

仅 Version B 安排。重点是 Northwest Coast Indigenous art，与 Québec 的 Wendake 温达克 形成东西部文化呼应。

Notre-Dame Basilica 蒙特利尔圣母大教堂 · Montréal 蒙特利尔

两套路线固定保留。Old Montréal 蒙特利尔老城 核心建筑，可与老城步行路线自然衔接。

Notre-Dame de Québec 魁北克圣母圣殿主教座堂

并入 Old Québec 魁北克老城 步行路线，与 Château Frontenac 芳堤娜城堡、Petit-Champlain 小香普兰街 和《鬼怪》取景区域一起完成。

Montréal 蒙特利尔 Museum of Fine Arts 蒙特利尔美术馆：Version A 有更充裕时间，建议作为 10/2 或 10/3 的可选项目；Version B 行程更紧，仅在天气不佳时替换 Mount Royal 皇家山 或其他户外项目。
Booking Notes

交通与预订执行要点

Rockies

  • Moraine Lake 梦莲湖 Road 私家车禁止进入，需使用 shuttle / Roam / 授权交通。
  • Icefields Parkway 冰原大道 9 月底需实时关注天气与路况。
  • 酒店优先比较 Banff 班夫 / Canmore 坎莫尔，不建议为了住宿体验长期住高价 Lake Louise 露易丝湖。

East Canada

  • Montréal 蒙特利尔 与 Old Québec 魁北克老城 城内无需租车。
  • Québec 郊区只在 Jacques-Cartier / Île d’Orléans 奥尔良岛 / Wendake 温达克 使用租车或包车。
  • Toronto 多伦多 与 Niagara 若选择 Version B，建议提前锁定晚间 Toronto 多伦多→Montréal 蒙特利尔 交通。

Budget

  • 国际机票已按约 ¥7,000/人计入。
  • 预算按 C$1 ≈ ¥4.85 做规划换算。
  • 实际总价最敏感的项目是 Rockies 酒店与加拿大国内航班。
